# LexInsights Screenshot Catalog

This catalog documents the organized screenshot archive under `public/screenshots` and the composed mockup boards under `public/mock-ups`. The captures are grouped by feature area so reviewers can inspect the app by workflow, viewport, and theme. Each section embeds two representative captures; the linked directory holds the full viewport/theme matrix.

> **Capture date:** 2026-07-06/07. The archive predates the 2026-07-08+ feature wave (PDF in the report download menu, matters dialog, plan-limits panel, corpus-coverage section in Help & Resources), so a recapture pass is due before the next external showcase.
